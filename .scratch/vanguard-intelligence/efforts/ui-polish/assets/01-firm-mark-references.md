- **Date of research:** 2026-08-12
- **Scope:** For each of the six firms in the fact base (Vanguard, BlackRock, Fidelity, State Street, Invesco, Amundi), the official public source for its mark, the distinctive element the hand-rendered SVG should capture, and the brand hue to use when the color prop is not overridden. This ticket feeds the shared firm-mark component (ticket 22) and its placements (ticket 24); it does **not** reproduce any trademarked artwork — the component is a hand-rolled, simplified, recognizable mark per the spec's standing rule ("recognizable at 24–32px, not pixel-perfect trademark reproductions").
